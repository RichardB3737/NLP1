# NLP1 Project 1

This project explores text classification using the TweetEval stance detection datasets. It compares classifiers, text representations, and cross-validation results.

## Notebooks

- `Project1/project.ipynb` — Project brief, task guidance, and checklist.
- `Project1/data_vis.ipynb` — Loads the Hillary stance dataset and visualizes its label distribution.
- `Project1/Implementation.ipynb` — Implements and evaluates classifiers on the climate stance dataset using token-indicator and bag-of-words representations, logistic regression, and multilayer perceptrons.

## Python modules

The `Project1` package contains the supporting code for tokenization, feature encoding, classification, cross-validation, utilities, and result analysis.

## Results

`Project1/results/` contains saved model files from the cross-validation runs.
